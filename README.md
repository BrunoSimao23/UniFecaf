# Biblioteca Digital UniFECAF — Projeto de Design Web

Projeto acadêmico de interface para a Biblioteca Digital UniFECAF, construído com HTML5 semântico e CSS3, sem frameworks ou JavaScript.

## Estrutura
```text
biblioteca-unifecaf/
├── index.html
├── css/
│   └── style.css
├── assets/
│   └── imagens/
└── README.md
```


## O que foi implementado
- Navegação por âncoras para Início, Biblioteca, Livros, Unidades e Contato.
- Layout fluido com Grid e Flexbox.
- Media queries para desktop, tablet e smartphone.
- Menu móvel expansível por CSS.
- Hierarquia semântica (`header`, `nav`, `main`, `section`, `article`, `footer`).
- Link para pular ao conteúdo, textos alternativos para ilustrações, foco visível do teclado e suporte a `prefers-reduced-motion`.
- Capas e ilustrações construídas em CSS para manter os arquivos leves e evitar dependência de imagens externas.

## Observações acadêmicas
- Os títulos de livros são ilustrativos e não representam registros reais do acervo.
- O endereço de e-mail exibido é demonstrativo. Confirme os canais oficiais da instituição antes de utilizar.
- A identidade visual é uma proposta acadêmica inspirada em uma linguagem institucional azul, com tons complementares e contraste elevado; não é apresentada como manual oficial da UniFECAF.
